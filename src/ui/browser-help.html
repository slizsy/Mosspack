Your browser needs one setting turned on

Mosspack runs on JSPI (WebAssembly JavaScript Promise Integration). Recent versions of Chrome, Edge and Brave have it on already. If you're seeing this page, your browser is either out of date or has it switched off. It takes about a minute to fix.

Detected: your browser
  1. Update Brave
    Menu → About Brave. Updating usually fixes it on its own, so try the game again first.
  2. Still not working? Open this address in a new tab
    brave://flags/#enable-experimental-webassembly-jspi
    Browsers don't let pages open settings links, so paste it into the address bar yourself.
  3. Set "Experimental WebAssembly JavaScript Promise Integration" to Enabled
    Show screenshot
  4. Click Relaunch, then open Mosspack again
  1. Update Chrome
    ⋮ menu → Help → About Google Chrome. Chrome 137 and newer have JSPI on by default.
  2. Still not working? Open this address in a new tab
    chrome://flags/#enable-experimental-webassembly-jspi
    Show screenshot
  3. Set "Experimental WebAssembly JavaScript Promise Integration" to Enabled
    On older or modified versions it may just be called "Experimental WebAssembly".
    Show screenshots
  4. Click Relaunch, then open Mosspack again
    Show screenshot
  1. Update Edge
    … menu → Help and feedback → About Microsoft Edge.
  2. Still not working? Open this address in a new tab
    edge://flags/#enable-experimental-webassembly-jspi
    Show screenshot
  3. Set "Experimental WebAssembly" to Enabled
    Show screenshots

Firefox support for JSPI is still experimental and can be unstable. Brave, Chrome or Edge will give you a much better experience.
  1. Update Firefox, then try again
  2. Still not working? Open this address in a new tab
    about:config
    Show screenshot
  3. Search for this setting and set it to true
    javascript.options.wasm_js_promise_integration
    Show screenshots
  4. Reload this page
Safari doesn't support JSPI yet, and there's no setting to turn it on.
  1. Open Mosspack in Brave, Chrome or Edge instead
    In Finder, right-click the Mosspack file → Open With → Brave Browser (or Google Chrome).
Changed a setting or updated? Click Try again. If the browser asked to relaunch, do that first.
